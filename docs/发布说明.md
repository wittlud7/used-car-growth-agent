# 公开演示与源码

- 网站：https://intent-car-agent.youngcoin22.chatgpt.site
- GitHub：https://github.com/wittlud7/used-car-growth-agent

本地完整版使用Python/SQLite；`online/` 是为Sites的Cloudflare Workers/D1环境适配的独立线上入口。两版均真实调用DeepSeek，使用合成车源和咨询，不执行对外预约或客户消息发送。

线上支持买卖匹配、工具轨迹、多轮需求、车辆对比、人工确认待办、浏览器批量处理及已保存的实测对照。线上每IP每天最多20次模型请求，全站每天120次；每轮可能包含多次模型请求，按UTC自然日计数。D1的原子条件更新限制额度，失败的预留不回退，避免并发超额。新建对话每IP每天60次。

对话和确认待办存放D1，读写按访客身份校验。匿名访客使用HttpOnly、SameSite Cookie；清除Cookie后无法恢复旧访客记录。批次报告和人工备注只在当前浏览器保存，继续处理下一条需要保持页面打开。平台提供已登录身份时使用该身份隔离。

线上待办是本地系统记录，未与车商/CRM集成，不是预约凭证。卖车候选需要人工核实买家需求；确认前必须勾选核查。对照页展示2026-10-25已保存的真实实验，不冒充本轮在线生成的结果。

## 运行与发布

本地Python：`python server.py --port 8765`。

线上开发：进入`online`，`npm ci`、`npm run build`，使用Wrangler本地预览。先生成并执行D1迁移，详细步骤见online/README.md。云端只通过Sites发布工具保存版本和部署，不运行Wrangler直接部署。

运行时秘密通过Sites环境变量设置：`DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`SESSION_SECRET`。不把值写进源文件、Git历史、部署清单、浏览器或构建产物。原始settings.json、数据库、日志、浏览器状态和本地预览凭据均排除。
